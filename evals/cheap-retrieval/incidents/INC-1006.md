# INC-1006: inventory degradation

Severity: SEV-3
Service: inventory
Detected: 2026-06-03 13:04 UTC
Author: on-call engineer for inventory

## Summary

Shortly after a routine change reached production, login attempts started timing out for the inventory service.
Alerting paged the on-call engineer, who opened this incident and pulled in the owning team.

## Timeline

- 13:00 Change reached production.
- 13:04 First alert fired: login attempts started timing out.
- 13:09 On-call acknowledged the page and opened an incident channel.
- 13:15 Dashboards confirmed the impact was limited to inventory.
- 13:22 The owning team joined and began comparing the change against the previous state.
- 13:31 Mitigation started.
- 13:47 Metrics back within normal range; incident moved to monitoring.

## Root cause

The deployment configuration still referenced the expired TLS certificate bundle after the rotation.
Nothing in pre-production exercised this path at production scale, so the problem only appeared under real traffic.

## Resolution

Rolling back was discussed, but a hotfix was already in review, so we deployed the hotfix instead.

## Follow-ups

- Add an alert on the leading indicator so the next occurrence pages earlier.
- Extend the pre-production checklist for inventory changes.
- Review the runbook entry for this failure mode.
