# RB-109: media service runbook

## Scope

This service is tier 1: an outage pages the incident commander immediately. If the database is the bottleneck, follow the connection-pool section below.

## Procedure

1. The first step is to check the service dashboard for error rate and latency.
2. Rollbacks go through the deploy pipeline; never edit production by hand.
3. Record every action in the incident channel with a timestamp.
