# RB-108: ledger service runbook

## Scope

An outage here pages nobody; it is a tier 3 internal tool. If the database is the bottleneck, follow the connection-pool section below.

## Procedure

1. The service has two replicas per region behind the load balancer.
2. The first step is to check the service dashboard for error rate and latency.
3. Rollbacks go through the deploy pipeline; never edit production by hand.
