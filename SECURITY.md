# Security policy

Please report suspected vulnerabilities privately to the maintainers through
[GitHub's private security advisory flow](https://github.com/foxhatleo/leos-agent/security/advisories/new).
Do not open a public issue for a vulnerability or include credentials, tokens,
or private reproduction data in a report.

Include affected version(s), harness and operating system, a minimal
reproduction, impact, and any suggested mitigation. We will acknowledge the
report, investigate privately, and coordinate disclosure and a fix when needed.

The command guard is an accident-prevention measure, not a security sandbox.
Review plugin hooks before trusting them and rely on each harness's permissions
and sandbox for isolation.
